## 🚀 How to Run

### Python Experiments (AI & ML)
Ensure you have Python 3.x installed along with standard data science libraries (`numpy`, `pandas`, `matplotlib`, `scikit-learn`):

```bash
# Run AI Practicals
python AI/Practical_1.py
python AI/Practical_3.py
python AI/Practical_5.py

# Run ML Practicals
python ML/ML_1/Practical_1.py
python ML/ML_5/Practical_5.py
python ML/ML_10/Practical_10.py
```

### Prolog Experiments (AI)
Install [SWI-Prolog](https://www.swi-prolog.org/) to run `.pl` files:

```bash
swipl AI/Practical_7.pl
```
